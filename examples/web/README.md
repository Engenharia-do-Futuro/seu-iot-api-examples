# Web examples

Browser examples that need no build step or server: open the HTML file directly.

| Example | What it does |
|---|---|
| [widget-embed](widget-embed) | A page that embeds a Seu IoT chart widget with a single `<script>` tag, and shows how to switch its light/dark theme live from the host page. |

The widget uses a public `embed_token`, safe to expose in a browser. It is never your API key. See [Widgets](../../docs/en/widgets.md).
