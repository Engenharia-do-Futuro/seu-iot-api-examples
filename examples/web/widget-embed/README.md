# Web - embeddable widget

`index.html` simulates a third-party page that pastes a Seu IoT widget `<script>`. Replace `EMBED_TOKEN` (see the comment in the file), then open it directly in a browser - no server needed.

The `embed_token` is a **public** credential meant to be visible in visitors' browsers; it never exposes your API key. See [Widgets docs](../../../docs/en/widgets.md).
